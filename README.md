# Goldstein HQ — Mint / Reveal UX Prototype

This repo is Matt's independent UI/UX sandbox for Goldstein Group.

## Current prototype

The first page focuses only on the NFT / Seat mint flow:

- 1,500 public paid mints
- 0.025 ETH per Seat
- quantity selector up to 5 Seats per transaction
- simulated wallet connection
- simulated mint / reveal flow
- Keep vs Reroll decision
- reroll starts at 0.00125 ETH-equivalent in $GLDSTN
- reroll price doubles after every reroll
- rerolled Seat returns to the available pool
- rank progression is explicitly separate from the random NFT draw
- Seat utility includes G-Fund access and the ability to launch an agent-managed fund

## Important

This is a front-end prototype only. There are no live contracts, wallet transactions, token integrations or real minting logic.
